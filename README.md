# 用药提醒

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)
[![Android](https://img.shields.io/badge/Android-8.0%2B-3DDC84.svg)](https://developer.android.com/)

一个 Android 本地优先的用药提醒 MVP，支持 Android 8.0（API 26）及以上版本。它使用系统闹钟、前台播放服务与中文 TTS，在锁屏或应用未运行时提醒患者药品名称、剂量、服用方式、重要说明与忌口事项。

## 当前功能

- 单患者、完全本地、无需登录
- 多药品、多时间点和按星期重复
- 药量、单位、服用方式、一般说明与忌口说明
- 精确闹钟、高优先级通知、锁屏提醒页和中文 TTS
- 奶油暖白、蜜桃与鼠尾草绿的陪伴型界面，以及更柔和的锁屏提醒页
- 已服、稍后提醒、跳过、漏服状态与今日记录
- 开机、应用更新、系统时间和时区变化后的重新调度
- 通知、精确闹钟、全屏提醒、后台限制与音量检查，以及 30 秒退出后台真实测试
- 温柔陪伴、可爱童声、严肃清晰、专业医护四种合成语音风格，并支持高级微调和立即试听
- 每次语音提醒播报当前本地时间，并按同一药品的“已服”记录说明距上次用药的间隔
- TTS 失败时使用间隔播放的柔和系统提示音兜底
- 缺少精确闹钟权限或系统拦截后台语音时，改用有声高优先级通知；若通知也不可用则自动重新排队
- 药品编辑后保留历史剂量和医嘱快照
- 医疗数据不上传，并关闭云备份与设备迁移备份

## 架构

- UI：Jetpack Compose + Material 3，包含今日、用药计划、设置和锁屏提醒页
- 数据：Room 保存药品、时间规则和不可变的每次服药事件；DataStore 保存提醒偏好
- 调度：AlarmManager 只维护最近一次系统闹钟；授权后使用用户可见的精确 AlarmClock，到点后生成下一次事件
- 播放：前台 Service 聚合当前所有到期药品，重复中文播报；通知和锁屏页共用同一状态
- 恢复：开机、应用升级、系统时间或时区改变后重新计算和注册闹钟

计划规则与每次实际发生的服药事件分开保存。这样编辑或停用计划不会改写“当时提醒了什么”，也便于后续增加照护者同步和依从性统计。

## 安全边界

本应用是提醒工具，不是医疗器械。剂量、忌口和其他医嘱必须由患者、照护者、医生或药师确认后录入；应用不会自动生成医疗建议。点击“已服”只代表用户进行了确认，不能证明药物已经服下。

本项目按“原样”提供，不承诺提醒在所有品牌手机、系统版本、省电策略或异常环境下均能送达。用于真实患者前，请在目标设备上完成锁屏、重启、省电模式、强制停止恢复和系统升级场景测试，并保留必要的备用提醒方式。

## 构建要求

- JDK 17
- Android SDK Platform 36
- Android Build Tools 35 或更高版本

在 Android Studio 中打开项目并完成 SDK 同步，或在 Windows 终端运行：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

APK 会生成在 `app/build/outputs/apk/debug/app-debug.apk`。

## 首次真机验证

1. 安装后进入“设置”，允许通知、精确闹钟和锁屏全屏提醒。
2. 确认系统闹钟音量不为零，并安装了可用的中文系统语音。
3. 在“声音与语气”中选择一种风格并点击“立即试听当前风格”；如手机提供多种中文 TTS 音色，也可进入系统语音设置选择更合适的本地中文音色。
4. 点击“30 秒后台真实提醒测试”，随后返回桌面、划掉最近任务或锁屏，确认仍会收到语音提醒。
5. 再添加一条短时间测试计划，验证“已服”“稍后提醒”和“跳过”都会停止或更新播报。

四种风格通过播报文案、TTS 音调、语速和相对音量共同实现，并优先选择手机中的本地中文音色。“可爱童声”和“专业医护”均为合成语音风格，不代表真实儿童或医生；不同品牌手机的基础音色和听感会有差异。

普通返回、回到桌面、划掉最近任务或应用进程被系统回收，不会主动取消已经注册的提醒。系统设置中的“强行停止”则是 Android 的强制边界：系统会停止应用并可能取消 PendingIntent，任何普通应用都不能绕过；再次主动打开应用后会重新注册后续提醒。

## MVP 边界

当前版本是单患者、单设备、完全本地的 MVP，不包含账号、云同步、照护者远程提醒、处方识别、药物相互作用判断或医疗建议。正式用于真实患者前，还需要在目标品牌手机上做息屏、重启、省电模式和系统升级场景测试；在完成这些验证前请保留备用提醒方式。
